# AI-Canvas 逐帧拉片插件

这是一个面向 `ai-video` / `source-video` 节点的 Plugin API v1 工具。它在 AI-Canvas 主窗口弹窗内完成选帧、视觉分析与结果编辑，然后一次生成图片节点或分镜表。

## 功能

- 均匀采样、区间采样、手动时间码和胶片点击选帧。
- 单次最多 24 帧，批量抽帧路径与 AI-Canvas 内部视频编辑器一致。
- 只列出支持图片输入的文本模型，用一张带 key/时间码的联系表完成批量分析。
- 可编辑景别、运镜、画面内容、台词、声音、转场、时长与备注。
- 可输出纯图片节点，或输出图片节点、分镜表及真实画面绑定。

## 宿主要求

需要包含以下 Plugin API v1 能力的 AI-Canvas 版本：

- `video.extractFrames` 宿主 effect；
- invocation 内 `derived` 图像资源；
- `create-node-set` 原子节点集输出。

当前宿主尚未正式发布这些能力时，请使用包含对应实现的 AI-Canvas 本地构建。插件不会自行安装 FFmpeg，也不会直接读取本地路径。

## 本地安装

1. 在 AI-Canvas 设置中打开“插件”。
2. 选择“从文件夹导入”，选择本仓库根目录。
3. 在视频节点工具栏或右键菜单中选择“逐帧拉片”。
4. 选择画面和视觉文本模型，开始分析；修订后生成所需节点。

模型调用会使用你在 AI-Canvas 中已经配置的厂商，可能产生费用。纯视觉画面无法证明的台词或声音应保留为“无法从画面判断”。

## 开发验证

要求 Node.js 20 或更新版本，不需要安装任何 npm 依赖。

```powershell
npm test
npm run build
```

`npm run build` 不做 bundling：它检查 `main.js` / `ui.js` 语法、更新 `manifest.ui.integrity`，再校验发布结构。修改 `ui.js` 后必须提交同步更新的 Manifest。

## 精度边界

v1 按时间点请求画面，并保存宿主返回的实际媒体时间。对可变帧率或长 GOP 视频，不承诺“绝对第 N 帧”精度；需要严格帧号定位时应另行评审原生解码依赖与跨平台体积。
