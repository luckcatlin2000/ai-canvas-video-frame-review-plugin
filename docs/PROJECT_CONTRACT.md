# 项目合同

## 目标用户与问题

AI-Canvas 视频创作者需要在当前视频节点内快速指定时间点、查看批量抽帧、调用视觉模型整理镜头语言，并把结果直接放回画布继续制作。

## v1 范围

- 入口仅匹配 `ai-video` 与 `source-video`。
- 在主窗口插件 Modal 内提供均匀、区间、手动时间码和胶片点击四种选帧方式。
- 单次最多分析 24 帧；使用一张带 key/时间码的联系表完成一次多模态分析。
- 分析结果可编辑，并支持“仅生成图片节点”或“N 个图片节点 + 1 个分镜表节点”。
- 使用宿主 `video.extractFrames`、派生资源租约和 `create-node-set`，插件不接触真实路径。

## 非目标

- 不提供视频剪辑、转码、音频识别或逐帧 OCR。
- 不保证 VFR、长 GOP 视频的绝对第 N 帧精度；v1 以请求时间和宿主返回的实际帧时间为准。
- 不自行联网、不内置模型、不绕过宿主模型费用与权限提示。
- 本仓库不发布远程仓库或 Release，除非用户另行授权。

## 验收

- `npm test` 覆盖两种输出、节点绑定、上限和 Manifest integrity。
- `npm run build` 对两个入口做语法检查、更新 SHA-256，并验证权限、版本、体积、路径与网络边界。
- 安装到具备 `video.extractFrames` 与 `create-node-set` 的 AI-Canvas 后，主窗口内完成抽帧、分析、编辑与原子节点生成。

## 保持不变

- 不新增依赖，不修改 AI-Canvas 的 Tauri CSP、文件 scope、IndexedDB schema 或 Agent/MCP 权限。
- 关闭或取消弹窗时不留下图片文件；只有最终提交才由宿主落盘。
