# 项目合同

## 目标用户与问题

AI-Canvas 视频创作者需要在当前视频节点内快速指定时间点、查看批量抽帧、调用视觉模型整理镜头语言，并把结果直接放回画布继续制作。

## v1 范围

- 入口仅匹配 `ai-video` 与 `source-video`。
- 点击工具默认打开大尺寸可滚动弹窗；关闭按钮左侧提供“在独立窗口打开”，由宿主创建无 iframe 的独立 Tauri 窗口。打开或聚焦成功后自动关闭原弹窗，失败时保留原编辑；未保存草稿不跨会话迁移。提供固定间隔、指定帧、自动镜头三种采样，胶片支持横向浏览和点击定位；窗口声明不增加权限。
- 左侧大舞台显示原视频播放器，可播放、暂停、拖动进度条，并与当前帧预览切换；点击胶片/逐帧定位会同步原视频位置。读取原文件，不转码、不自动播放；内存预览上限 16 MiB，超限或格式不支持时提示，仍可抽帧分析。右侧步骤栏按采样、校正、分析组织参数，900px 以下移至预览和胶片下方；步骤切换保留配置，未应用的采样参数会阻止分析并提示先应用。
- 支持镜头拆分、连续镜头合并、邻接边界前后移动实际一帧及撤销/重做；每镜选择首、中、尾或指定代表帧。
- 单次最多分析 24 帧；使用一张带 key/时间码的联系表完成一次多模态分析。
- 分析结果可编辑，展示模型自报置信度、AI 原文和人工覆盖，支持“仅生成图片节点”或“N 个图片节点 + 1 个分镜表节点”。镜头 ID、来源节点/名称、入出点和时长同时写入图片与分镜行。
- 结果支持本地一键转线稿及原图对照，不调用模型。节点、分镜和联系表按当前显示输出：原图使用原帧/JPEG 联系表，线稿使用宿主 PNG/SVG 联系表；结构化 JSON/CSV 标明画面模式，保留人工复核内容。输出保存到当前项目，不通过页面下载或访问任意本地路径。
- 使用宿主 `video.extractFrames`、派生资源租约和 `create-node-set`，插件不接触真实路径。

## 非目标

- 不提供视频剪辑、转码、音频识别或逐帧 OCR。
- 不保证 VFR、长 GOP 视频的绝对第 N 帧精度；v1 以请求时间和宿主返回的实际帧时间为准。
- 不自行联网、不内置模型、不绕过宿主模型费用与权限提示。
- 自动检测采用有界帧差：单次最多 300 秒、36,000 个解码帧、128 镜或 120 秒处理时间；适合硬切初筛，不承诺准确识别叠化、摇镜和复杂闪光，不是 PySceneDetect/TransNetV2 的替代实现。
- 不恢复跨会话草稿、不跟踪重新剪辑版本。镜头 ID 在本次会话编辑及输出中稳定，不声称跨视频身份匹配。
- 本仓库不发布远程仓库或 Release，除非用户另行授权。

## 验收

- `npm test` 覆盖两种输出、节点绑定、上限和 Manifest integrity。
- `npm run build` 对两个入口做语法检查、更新 SHA-256，并验证权限、版本、体积、路径与网络边界。
- 需要同时更新宿主：须具备 `video.extractFrames`（支持 replaceDerived）、`video.detectShots`、`video.inspectFrame`、`resource.export` 与 `create-node-set`，并将 UI 分段读取单独按 96 次/16 MiB 限额。线稿还要求宿主支持固定 image.lineArt 操作及节点集 representation 表示；不支持时明确提示更新主应用。旧宿主不能只更新插件后使用新增功能。
- 浏览器模拟宿主可验证滚动、选帧、人工复核和提交协议；不能替代真实 Tauri 中的解码、模型调用和项目写入验收。
- 宿主已接入手动独立窗口入口；Windows 实机已观察专用窗口的 24 项基础探针、重复聚焦、合成报告写回和本插件视频缩略图加载。全部生命周期、双主题/缩放、真实媒体输出及其他平台验收仍须分别记录，不把这些基础证据当作全量验收。

## 保持不变

- 不新增依赖，不修改 AI-Canvas 的 Tauri CSP、文件 scope、IndexedDB schema 或 Agent/MCP 权限。
- 未主动导出或提交时关闭弹窗不留下图片文件；主动导出的报告/联系表保留在项目内，过期操作的文件由宿主回收。
