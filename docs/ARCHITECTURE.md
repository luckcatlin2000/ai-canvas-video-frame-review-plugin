# 架构与数据流

## 文件边界

- `manifest.json`：声明节点入口、最小权限、自定义 UI、允许输出的节点类型和字段。
- `ui.js`：负责原视频播放、选帧、请求宿主模型和结果编辑。Manifest 声明 `dialog.presentation: "window"`，表示支持手动另开宿主创建的无 iframe 专用 Tauri WebView。节点工具默认仍打开 sandboxed iframe 弹窗；标题栏关闭按钮左侧的独立窗口按钮另开会话，创建或聚焦成功后自动关闭原弹窗，失败则保留。未保存草稿不自动迁移。
- `main.js`：QuickJS 最终写回入口，只把 UI 提交的数据映射成受控节点集。
- `scripts/`：只使用 Node.js 内置模块进行 syntax、integrity 和发布结构校验。

## 主流程

1. UI 从 `resources.self` 选择当前节点的视频不透明句柄。
2. 首个 `video.extractFrames` effect 生成 12 张有界胶片预览。左侧大舞台显示原视频或当前帧，下方胶片用于预览定位；右侧以采样、校正、分析三个步骤组织参数，使用现有 `resource.readRange` 顺序读取，每段 180 KiB（Base64 低于宿主 256,000 字符上限），校验句柄、偏移和字节数后在当前页面组装 Blob；不转码、不暴露源路径、不跨页面传递 Blob URL、不自动播放。原视频内存预览上限 16 MiB，超限或格式不支持时提示并保留抽帧功能。点击胶片或逐帧定位时暂停原视频并同步位置。
3. 用户用固定间隔、指定时间码或 `video.detectShots` 建立镜头区间。最多保留 128 镜，每批显式勾选最多 24 镜；每镜可选首、中、尾或当前帧作为代表。
4. `video.inspectFrame` 复用宿主真实样本时间戳进行前后帧检查及边界校正；拆分、合并和边界修改保留稳定镜头 ID，邻接区间同步移动，支持 30 步会话内撤销/重做。
5. `video.extractFrames` 的 analysis 模式传 `replaceDerived: true` 原子替换当前派生批次。同一镜头集合重试复用已抽取联系表；选择/区间/代表帧变化后旧分析作废。
6. 可仅抽帧后人工填写；也可通过 `model.generate` 分析联系表，按镜头 key 对齐 JSON。模型置信度是自报值，缺失记为 null；`aiOriginal` 保存原文，`overrideFields` 标记人工覆盖。重试不会覆盖人工字段，改动后重新复核。
7. UI `submit` 后，`main.js` 返回 `create-node-set`：图片节点携带帧 `resourceId`，分镜行使用临时 `frameKey`。
8. 宿主保存图片、生成真实 nodeId、解析分镜绑定和内部边，并通过一次 Store Action 写入画布。图片与分镜行都保存 `frameAnalysis`，来源节点 ID/名称由宿主覆盖，时长只取出点减入点，不采用 AI 猜测。
9. JSON/CSV 报告走 `resource.createText`，联系表走 `resource.export`。只返回项目内文件名，不暴露路径；报告过滤临时句柄/预览内容并转义 CSV 公式，不将导出当作节点提交。

## 生命周期与恢复

- 派生图片只存在于当前 UI invocation 的内存租约中。
- 展示方式不改变 Plugin API v1 挂载函数与 props；插件不直接调用 Tauri、文件或通用事件。原生窗口只走专用会话桥接，主窗口持有资源、配额与唯一画布写入权威。
- 同一项目、节点和工具重复打开复用并聚焦已有窗口，启动组件卸载不结束独立会话。独立窗口重新聚焦时刷新主题；不通过通用事件订阅主窗口。
- 关闭、取消、换项目、改画布、停用插件或插件 revision 变化都会使租约失效。
- 窗口关闭或会话失效后丢弃迟到结果；不能承诺已提交的文本模型请求在远端停止或退费，不自动重试付费请求。原生独立 profile 不复用，但不承诺磁盘零缓存残留或草稿恢复。
- 同一选帧集合复用已抽取的联系表；模型失败仍保留抽帧供人工填写。自动检测失败不提交部分切镜结果，抽帧不完整时拒绝节点提交。
- 任一最终资源失效或节点集校验失败时整批拒绝；宿主负责回收本次准备阶段创建的文件。
- 当前 UI 会话的本地视频操作最多 96 次、分段读取最多 96 次且累计请求不超过 16 MiB、主动导出最多 12 次，模型及其他 effect 仍最多 4 次；总请求仍不超过 192 次。读取不消耗模型额度；失败读取也计入预算。关闭前请导出报告或生成节点，尚不支持重开恢复编辑草稿。
- 宽窗口采用左侧大预览及下方胶片、右侧 320–350px 参数栏；900px 以下参数栏移至舞台与胶片下方。右侧按 01 采样、02 校正、03 分析切换，仅改变显隐，不重建表单或丢弃编辑。采样参数未应用时提示并阻止分析/人工抽帧；采样页下一步会先应用修改。分析页纵向展示选中数量、模型、要求和主操作；人工抽帧不要求模型。
- 胶片使用 CSS 透视层叠与最近预览帧前凸，提供立体/平铺切换；前凸仅表示视觉聚焦，精确当前帧标记仍按真实时间判断。沿用初始预览资源，不额外抽帧、不改变勾选语义。滚轮、触控板、方向键及左右按钮继续有效，隐藏滚动条且不保留空槽。
- 视觉以中性黑灰和低饱和灰紫为底，参数卡仅有局部淡紫光泽，不使用整面背景模糊。胶片通过细侧边、遮挡和焦点前凸形成薄片队列，勾选只显示小标记。当前帧复用左侧舞台，显示实际时间与预览所属镜头；右侧单独标明正在编辑的镜头，跨边界预览不会冒充编辑对象切换。视频加载与错误提示在所有断点保持可见。
- 点击胶片、定位和逐帧检查后暂停原视频并切到当前帧；返回原视频不会自动播放。结果在独立全宽区域复核，分析/人工抽帧成功后滚动并聚焦结果标题，提供查看结果和返回工作台入口；镜头变化后旧结果及入口一同隐藏。步骤标签支持方向键、Home/End，导航始终保留明确键盘焦点。
- UI 使用自身深浅主题变量；减少动态效果设置关闭卡片过渡并使用即时滚动。底部状态提示与输出按钮保持同排，窄窗口允许换行。
- 关闭时暂停播放器、卸载媒体并撤销当前页面的 Blob URL；分段读取在每轮异步返回后检查销毁状态，关闭后不再请求剩余数据或创建播放器。
